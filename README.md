# ⏱️ Complexity Checklist

For every solution, try to identify:

```text
┌─────────────────────────────────────┐
│          ⏱️ TIME COMPLEXITY         │
├─────────────────────────────────────┤
│ How many operations are performed?  │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│          💾 SPACE COMPLEXITY        │
├─────────────────────────────────────┤
│ How much extra memory is required?  │
└─────────────────────────────────────┘
```

Example:

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}
```

Complexity:

```text
Time  → O(n)
Space → O(1)
```

# 🔥 Rules For This Journey

### Rule 1 — Don't Memorize Blindly

Understand **why** an algorithm works.

### Rule 2 — Code It Yourself

Try implementing the concept before looking at a solution.

### Rule 3 — Start With Brute Force

First find a working solution.

Then optimize it.

### Rule 4 — Analyze Complexity

Always ask:

```text
Can I make it faster?
Can I use less memory?
```

### Rule 5 — Practice Consistently

Consistency matters more than solving hundreds of problems in a few days.
